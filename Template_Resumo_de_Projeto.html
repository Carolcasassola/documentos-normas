Como usar este template Preencha os campos destacados em cinza-itálico (áreas tracejadas) com as informações do seu projeto. Copie esta página para cada novo projeto/sistema e mantenha o roadmap atualizado a cada marco concluído.

💡 Instruções de Preenchimento

✅ Boas práticas
Use linguagem objetiva e evite termos genéricos
Atualize o roadmap a cada marco concluído
Reavalie os riscos periodicamente
📎 Antes de compartilhar
Revise se todos os campos tracejados foram preenchidos
Valide o conteúdo com os responsáveis indicados
Exporte ou salve uma cópia para o histórico do projeto
